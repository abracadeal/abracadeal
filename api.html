API partenaires

Éditeurs de logiciels immobiliers et automobiles : diffusez les annonces de vos clients sur Abracadeal, automatiquement. La diffusion est gratuite pour les agences et les garages.

Version 1 — mise à jour le 5 novembre 2026. Contact technique : contact@abracadeal.fr

Principe

  1. Votre client active Abracadeal dans votre logiciel. C'est son accord pour la diffusion.
  2. Vous déclarez l'agence (PUT /v1/agencies/{agency_id}) avec son SIRET.
  3. Vous envoyez ses annonces (PUT /v1/agencies/{agency_id}/listings). Elles sont contrôlées puis mises en ligne, et mises à jour à chaque envoi.
Aucune inscription à faire pour l'agence. Si elle n'a pas encore de compte Abracadeal, nous l'ouvrons automatiquement à partir de votre déclaration : SIRET contrôlé au registre officiel, puis e-mail à l'agence pour choisir son mot de passe. Il faut pour cela son e-mail et son téléphone. Si l'ouverture automatique n'est pas possible, l'agence passe au statut pending et nous la traitons rapidement ; ses annonces sont ensuite acceptées sans action de votre part.

Accès

URL de base

https://jplzvxmpbpjssyinozap.supabase.co/functions/v1/partner-api/v1

Authentification : une clé par éditeur, fournie sur demande à contact@abracadeal.fr, à envoyer dans chaque requête :

Authorization: Bearer abk_live_xxxxxxxxxxxxxxxx

Les échanges se font en JSON (UTF-8), en HTTPS uniquement. POST est accepté partout où PUT l'est. Une clé de test est disponible pour vos développements.

agency_id est votre identifiant de l'agence : 1 à 80 caractères parmi A-Z a-z 0-9 . _ : -.

Déclarer une agence

PUT /v1/agencies/AG-1234
{
  "siret": "12345678900012",
  "name": "Agence du Port",
  "sector": "immobilier",
  "email": "contact@agenceduport.fr",
  "phone": "04 93 00 00 00",
  "city": "Cannes",
  "postal_code": "06400",
  "consent": true
}
ChampObligatoireDescription
siretoui14 chiffres. Ne peut plus changer une fois l'agence diffusée.
nameouiNom commercial de l'agence.
consentouitrue : l'agence a activé elle-même la diffusion sur Abracadeal dans votre logiciel.
sectornonimmobilier (par défaut) ou vehicules.
email, phonerecommandésIndispensables pour ouvrir automatiquement le compte de l'agence. Le téléphone est celui affiché aux acheteurs.
city, postal_codenonAdresse de l'agence.

Réponse (201 à la création, 200 ensuite) :

{ "ok": true, "agency": { "agency_id": "AG-1234", "status": "active", "status_detail": "Annonces acceptées.", … } }

Statuts : active (annonces acceptées), pending (compte en cours d'ouverture par Abracadeal), stopped (diffusion arrêtée ; un nouveau PUT la relance).

Envoyer des annonces

PUT /v1/agencies/AG-1234/listings
{
  "mode": "partial",
  "listings": [
    {
      "reference": "MANDAT-0456",
      "transaction": "vente",
      "type_bien": "appartement",
      "titre": "Appartement 3 pièces avec terrasse",
      "description": "…",
      "prix": 395000,
      "surface": 68,
      "pieces": 3,
      "chambres": 2,
      "ville": "Cannes",
      "code_postal": "06400",
      "dpe": "C",
      "ges": "C",
      "photos": ["https://…/1.jpg", "https://…/2.jpg"]
    }
  ]
}
  • mode: "partial" (par défaut) : les annonces envoyées sont créées ou mises à jour, les autres ne bougent pas. Retirez une annonce avec DELETE …/listings/{reference}.
  • mode: "full" : vous envoyez le stock complet ; les annonces absentes de l'envoi sont retirées.
  • 200 annonces maximum par appel. Une annonce identique à l'envoi précédent n'est pas retraitée.
  • reference est obligatoire : identifiant unique et stable du bien (numéro de mandat, de stock…). C'est lui qui relie vos mises à jour à l'annonce en ligne.

Réponse :

{ "ok": true, "mode": "partial", "received": 1, "created": 1, "updated": 0,
  "unchanged": 0, "removed": 0, "rejected": 0, "rejected_detail": null }

Une annonce incomplète (sans photo, sans ville, type non reconnu…) est refusée sans bloquer les autres ; la raison figure dans rejected_detail.

Toute erreur renvoie { "ok": false, "error": { "code": "…", "message": "…" } }.

Exemple complet

curl -X PUT "https://jplzvxmpbpjssyinozap.supabase.co/functions/v1/partner-api/v1/agencies/AG-1234/listings" \
  -H "Authorization: Bearer abk_live_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"mode":"partial","listings":[{"reference":"MANDAT-0456","transaction":"vente","type_bien":"maison","prix":520000,"ville":"Mougins","surface":120,"pieces":5,"dpe":"B","ges":"B","photos":["https://exemple.fr/1.jpg"]}]}'

Bon à savoir

  • Les annonces passent par nos contrôles automatiques (cohérence, photos, contenus interdits) avant publication, comme toute annonce d'Abracadeal. Voir les règles de diffusion.
  • Les annonces restent la propriété de l'agence. Abracadeal ne les transmet à aucun autre site.
  • Vous préférez un export existant (format SeLoger / Poliris par FTP, flux XML) ? Écrivez-nous : nous pouvons aussi le lire.
