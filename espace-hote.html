Mode voyageur

Créer votre compte hôte

Commencez par vos identifiants Abracadeal. Ensuite vous complétez votre profil, le logement et la carte bancaire.

1. Identité du loueur

Informations privées utilisées pour votre compte et vos obligations de location.

2. Statut du loueur

Le statut et le SIRET pourront être repris dans vos documents de location.

3. Votre premier logement

Adresse complète conservée dans l’espace privé ; la ville et le code postal servent à l’annonce.

4. Numéros réglementaires

Le numéro d’enregistrement du meublé doit pouvoir être affiché sur l’annonce.

5. Préparer l’annonce

Abracadeal conserve l’adresse exacte dans l’espace privé. Les informations nécessaires à l’annonce pourront ensuite être affichées conformément à la réglementation applicable.
Carte bancaire obligatoire pour tous les hôtes. Pour les 500 premiers logements, aucun débit pendant 12 mois : Stripe enregistre simplement le moyen de paiement pour l’abonnement futur. L’inscription hôte n’est finalisée qu’après cette étape.
