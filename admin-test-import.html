    Sites à apprendre

    Prospects dont le robot n'a pas su lire le site : ils reçoivent d'office le « mail normal », après ceux dont le site est lu. Tu n'as rien à faire, sauf pour un gros pro qui vaut une réparation. Tester : voir ce que lit le robot. Réparer : le site part dans « Sites en réparation » (si la réparation est impossible, bouton « Mail normal » là-bas) pour que ChatGPT ou Claude apprenne au robot à le lire. Valider : le site se lit bien maintenant → il est retesté et le pro reçoit son mail. Supprimer : ne m'intéresse pas, jamais de mail. Vend sur Leboncoin : mail « publiez vous-même vos annonces ». Mail normal : site qui bloque le robot → mail « publiez vous-même ou envoyez-nous le flux de votre logiciel ».
