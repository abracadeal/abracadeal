    Prospects dont le robot n'a pas su lire le site : ils ne reçoivent pas le mail. Tester : voir ce que lit le robot. Supprimer : ne m'intéresse pas, jamais de mail. Vend sur Leboncoin : mail « publiez vous-même vos annonces ».
