## Consignes pour ChatGPT

1. Lire le mail voulu (`.html` pour la mise en page, `.txt` en version texte brut).
2. Pour le mail Vacances, remplacer `{{nom}}` par le nom du destinataire. Le mail Pro commence par « Bonjour, » sans nom.
3. Envoi de test via Resend : envoyer le HTML avec la version texte en alternative.
4. Ne pas modifier les chiffres de l'offre, les signatures ni la ligne « STOP ».
